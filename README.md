# TKTrainer

Statyczna strona Tomasza Krężeloka, trenera personalnego w Katowicach.

Strona jest publikowana z katalogu głównego gałęzi `main` przez GitHub Pages. Plik `.nojekyll` zapewnia dostęp do zasobów w katalogu `_ds`.

Do podglądu lokalnego uruchom w tym katalogu `python -m http.server 8000`, a potem otwórz `http://localhost:8000/`.
